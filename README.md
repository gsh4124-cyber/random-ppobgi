# 랜덤뽑기

결과는 랜덤, 방식은 마음대로.

번호나 이름을 입력하고 상황에 맞는 게임 방식으로 무작위 선택을 진행하는 정적 웹 서비스입니다.

- 운영 주소: https://random-ppobgi.pages.dev/
- 현재 버전: v50

## 게임

사다리, 룰렛, 제비, 핀볼, 경주, 캡슐, 슬롯, 폭탄의 8가지 방식을 제공합니다.

## 개인정보 처리

현재 입력한 이름, 번호, 직접 입력 결과는 사용자의 브라우저 안에서만 처리되며 서버로 전송하거나 저장하지 않습니다. Cloudflare 대시보드에서 Web Analytics가 제공될 수 있으며, 서비스 코드에는 별도의 분석 또는 광고 스크립트를 넣지 않습니다. 자세한 내용은 서비스의 `/privacy/` 페이지에서 확인할 수 있습니다.

## 배포 구조

외부 프레임워크나 빌드 단계 없이 HTML, CSS, JavaScript 정적 파일을 GitHub 저장소에서 Cloudflare Pages로 배포합니다.

## 로컬 실행

저장소 루트에서 정적 파일 서버를 실행합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 루트의 `index.html`을 직접 열어도 기본 게임은 실행되지만, `/about/` 같은 경로 확인에는 정적 서버 사용을 권장합니다.
