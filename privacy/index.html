입력 내용

현재 랜덤뽑기는 회원가입 기능이 없으며, 사용자가 입력한 이름·번호·직접 입력 결과를 서버로 전송하거나 서버에 저장하지 않습니다. 이 내용은 현재 공개된 서비스 코드의 동작을 기준으로 하며, 입력값은 사용 중인 브라우저 안에서 추첨을 위해 처리됩니다.

Cloudflare Web Analytics

서비스 운영 상태와 이용 흐름을 파악하기 위해 호스팅 사업자인 Cloudflare의 Web Analytics가 사용될 수 있습니다. 이 기능은 Cloudflare 대시보드에서 제공될 수 있으며, 서비스 코드에 별도의 Cloudflare Analytics 스크립트를 중복 삽입하지 않습니다. Cloudflare의 처리 방식은 Cloudflare 정책의 적용을 받습니다.

외부 링크

문의용 GitHub Issues 등 외부 사이트로 이동하면 해당 서비스의 개인정보처리방침이 적용됩니다.

변경

향후 광고, 계정, 서버 저장 기능이 도입되면 실제 처리 내용에 맞춰 이 방침을 변경하고 시행일을 표시합니다. 현재는 Google Analytics와 광고 스크립트를 사용하지 않습니다.
